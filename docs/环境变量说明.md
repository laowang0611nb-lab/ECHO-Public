# ECHO 环境变量说明

> 适用版本：`0.0.297`
> 比赛集成分支：`0.0.x-274`
> 说明：分支名中的 `x` 是固定字母，不是版本占位符。代码版本仍必须是 npm 和 Python 可识别的数字版本。

## 1. 先确认实际部署版本

相同版本号不表示服务器一定运行的是最新构建。排障和评审前必须分别核对：

```powershell
# API 实际运行版本
Invoke-RestMethod http://127.0.0.1:8000/api/v1/health

# 公网 API 实际运行版本
Invoke-RestMethod https://echo.laowangworld.xyz/api/v1/health

# 当前仓库版本和分支
git branch --show-current
git describe --tags --always
Get-Content package.json
```

教师 Web 底部的 Web/API 版本来自实际构建和健康检查，不应根据域名、GitHub 标签或服务器目录名推断。

## 2. 配置文件位置

| 文件 | 用途 |
|---|---|
| `.env.example` | 跨端默认值和本地开发参考 |
| `apps/api/.env.example` | FastAPI、数据库、模型、短信和文件存储 |
| `apps/web/.env.example` | 教师 Web 的 API 地址和注册入口 |
| `apps/mobile/.env.example` | 学生端 API、教师 Web、鉴权模式和注册入口 |
| `apps/mobile/.env.adb.example` | USB ADB 联调 |
| `apps/mobile/.env.hotspot.example` | 电脑热点联调 |
| `apps/mobile/.env.public.example` | 公网正式包 |

真实密钥只写入被 Git 忽略的 `.env`，不得提交、打印到日志或写入客户端包。

## 3. 后端基础与部署

| 变量 | 示例 | 说明 |
|---|---|---|
| `ECHO_ENVIRONMENT` | `development` | `development`、`test` 或 `production` |
| `ECHO_DEPLOYMENT_MODE` | `local` | `local` 或 `public_demo` |
| `ECHO_PUBLIC_BASE_URL` | `https://echo.laowangworld.xyz` | API 对外基地址 |
| `ECHO_TEACHER_WEB_BASE_URL` | `https://echo.laowangworld.xyz` | 教师 Web 对外基地址 |
| `ECHO_DEVELOPMENT_AUTH_ENABLED` | `false` | 生产环境必须关闭 `X-User-Id` 开发认证 |
| `ECHO_PUBLIC_REGISTRATION_ENABLED` | `true` | 是否开放短信注册 |
| `ECHO_BUSINESS_TIMEZONE` | `Asia/Shanghai` | Dashboard 业务日期分桶时区 |

## 4. 数据库与认证

| 变量 | 示例 | 说明 |
|---|---|---|
| `ECHO_DATABASE_URL` | `postgresql+asyncpg://echo:...@localhost:5432/echo` | SQLAlchemy Async 数据库地址 |
| `ECHO_AUTH_SECRET_KEY` | 随机长字符串 | JWT 和验证票据签名密钥，生产环境必须更换 |
| `ECHO_AUTH_JWT_ALGORITHM` | `HS256` | JWT 签名算法 |
| `ECHO_AUTH_ACCESS_TOKEN_MINUTES` | `30` | Access Token 有效分钟数 |
| `ECHO_AUTH_REFRESH_TOKEN_DAYS` | `14` | Refresh Session 有效天数 |
| `ECHO_CORS_ORIGINS` | JSON 数组 | 允许访问 API 的教师 Web 来源 |

数据库迁移：

```powershell
apps/api/.venv/Scripts/python.exe -m alembic -c database/alembic.ini upgrade head
```

|---|---:|---|
| `ECHO_DOCUMENT_STORAGE_ROOT` | `tmp/uploads` | 教材 PDF 存储目录 |
| `ECHO_AVATAR_STORAGE_ROOT` | `tmp/avatars` | 头像存储目录 |
| `ECHO_CHAT_ATTACHMENT_STORAGE_ROOT` | `tmp/chat_attachments` | 聊天图片和音频存储目录 |

| `ECHO_CHAT_IMAGE_MAX_UPLOAD_BYTES` | `10485760` | 聊天图片上限，默认 10 MiB |
| `ECHO_CHAT_AUDIO_MAX_UPLOAD_BYTES` | `20971520` | 聊天音频上限，默认 20 MiB |
| `ECHO_CHAT_VIDEO_MAX_UPLOAD_BYTES` | `52428800` | 视频上限；当前比赛版建议关闭视频 |
| `ECHO_CHAT_VIDEO_ENABLED` | `false` | 是否开放聊天视频输入 |
| `ECHO_CHAT_ATTACHMENT_EXPIRY_HOURS` | `24` | 聊天附件保留小时数 |

比赛期间如需长期保留演示图片和语音，应关闭自动删除或将其保留期调大，并保留手动清理入口。

## 6. 并发与限流

| 变量 | 默认值 | 说明 |
|---|---:|---|
| `ECHO_DOCUMENT_PROCESSING_MAX_CONCURRENCY` | `1` | 同时解析的教材数量 |
| `ECHO_ANALYSIS_MAX_CONCURRENCY` | `1` | 同时执行的 AI 分析数量 |
| `ECHO_CHAT_RATE_LIMIT_PER_MINUTE` | `30` | 单用户聊天频率参考值 |
| `ECHO_SMS_SEND_PHONE_LIMIT_PER_HOUR` | `5` | 单手机号每小时短信上限 |
| `ECHO_SMS_SEND_IP_LIMIT_PER_HOUR` | `20` | 单 IP 每小时短信上限 |
| `ECHO_ANALYSIS_PROGRESS_HEARTBEAT_SECONDS` | `5` | 分析任务心跳写入间隔 |

## 12. 生产检查

- 生产密钥只存在于服务器环境变量或受限 `.env` 文件。
- `ECHO_DEVELOPMENT_AUTH_ENABLED=false`。
- `EXPO_PUBLIC_ALLOW_INSECURE_API_OVERRIDE=false`。
- 数据库仅监听本机，不对公网开放。
- Uvicorn 保持单 worker，Nginx 关闭 SSE 缓冲并保留 `/api/v1` 路径。
- 启动后从服务器实际调用 Chat、Embedding 和远程 ASR，不把“配置存在”当作连通成功。
- 部署完成后记录实际 API `/health` 版本、Web 构建版本和迁移 head。
