# 教师端缺失接口需求 v1

本文档登记教师端已经明确需要、但当前后端尚未提供的接口。前端在接口落地前只显示真实空状态，不使用估算、Mock 或本地伪造数据。

## 通用约定

- 统一前缀：`/api/v1`
- 鉴权：沿用教师端 `X-User-Id` 开发认证和现有课程成员权限校验。
- 所有列表接口应支持 `limit`、游标或稳定的分页参数，返回 `items`、`total`、`nextCursor`。
- 所有时间字段使用 ISO 8601；掌握度统一返回 `0-100` 的小数或 `null`。
- 接口不能返回无来源的推断结论；没有证据时返回空数组，并由前端显示空状态。

## P0：先补齐知识详情证据闭环

### 1. 知识点掌握趋势

```text
GET /api/v1/courses/{course_id}/knowledge-points/{knowledge_point_id}/mastery-trend?days=30
```

用途：替换知识详情页的“掌握趋势暂不可用”卡片，显示真实时间序列。

响应：

```json
{
  "knowledge_point_id": "uuid",
  "range": {
    "start_date": "2026-08-20",
    "end_date": "2026-09-18",
    "days": 30
  },
  "points": [
    {
      "date": "2026-09-01",
      "average_mastery": 62.5,
      "affected_students": 8,
      "evidence_count": 14
    }
  ]
}
```

验收：按日期升序返回；没有快照的日期可以由前端断开折线，不允许后端插值。

### 2. 知识点常见错误聚类

```text
GET /api/v1/courses/{course_id}/knowledge-points/{knowledge_point_id}/error-patterns?days=30&limit=10
```

用途：替换“常见错误暂不可用”卡片，展示可追溯到 LearningEvent 的错误模式。

响应：

```json
{
  "knowledge_point_id": "uuid",
  "window_days": 30,
  "patterns": [
    {
      "code": "boundary_missing",
      "label": "遗漏边界值",
      "description": "连续出现未覆盖边界条件的学习事件",
      "occurrence_count": 12,
      "affected_students": 5,
      "trend": "up",
      "sample_evidence_ids": ["uuid"]
    }
  ]
}
```

`trend` 只能是 `up`、`stable`、`down`、`unknown`。每个 pattern 必须能回查对应 LearningEvent。

### 3. 示例、习题与实验资源

```text
GET /api/v1/courses/{course_id}/question-items?knowledgePointId={point_id}&cursor=&limit=20
GET /api/v1/courses/{course_id}/question-items/{question_item_id}
POST /api/v1/courses/{course_id}/question-items
PATCH /api/v1/courses/{course_id}/question-items/{question_item_id}
DELETE /api/v1/courses/{course_id}/question-items/{question_item_id}
```

同时扩展资源类型：

```text
resource_type: textbook | outline | question_bank | code_example | lab | external_link
```

`question-item` 至少返回：

```json
{
  "id": "uuid",
  "course_id": "uuid",
  "knowledge_point_ids": ["uuid"],
  "type": "single_choice",
  "difficulty": "easy",
  "title": "string",
  "content": "string",
  "answer": "string|null",
  "explanation": "string|null",
  "source_document_id": "uuid|null",
  "source_page": 12,
  "created_at": "ISO-8601",
  "updated_at": "ISO-8601"
}
```

验收：知识点详情“相关习题”页签、知识库“示例与习题”页签使用同一套真实数据，不再显示接口缺失空状态。

### 4. PDF 文件流与页级定位

```text
GET /api/v1/courses/{course_id}/documents/{document_id}/file
GET /api/v1/courses/{course_id}/documents/{document_id}/pages/{page_number}
```

`file` 接口返回 `application/pdf`，支持 HTTP Range。`pages/{page_number}` 返回：

```json
{
  "page_number": 12,
  "width": 1240,
  "height": 1754,
  "text": "page text",
  "blocks": [
    {
      "chunk_id": "uuid",
      "text": "matched evidence",
      "bbox": [120, 240, 980, 360]
    }
  ]
}
```

验收：教材来源页可以渲染真实 PDF 页面；有 bbox 时绘制证据高亮，没有 bbox 时只定位页码，不伪造高亮。

## P1：知识库完整资源能力

### 5. 外部资源

```text
GET /api/v1/courses/{course_id}/external-resources?knowledgePointId=&status=&cursor=&limit=20
POST /api/v1/courses/{course_id}/external-resources
PATCH /api/v1/courses/{course_id}/external-resources/{resource_id}
DELETE /api/v1/courses/{course_id}/external-resources/{resource_id}
```

字段：`title`、`url`、`provider`、`description`、`knowledgePointIds`、`check_status`、`last_verified_at`、`created_at`。

验收：知识库“外部资源”页签显示真实列表；链接失效时显示后端校验状态，不在前端主动抓取外链。

### 6. 回收站、删除与恢复

```text
GET /api/v1/courses/{course_id}/resources?trashed=true&cursor=&limit=20
POST /api/v1/courses/{course_id}/resources/{resource_id}/trash
POST /api/v1/courses/{course_id}/resources/{resource_id}/restore
DELETE /api/v1/courses/{course_id}/resources/{resource_id}?permanent=true
```

验收：普通资源、章节、知识点删除后进入回收站；恢复保留原 ID、章节结构和引用关系；永久删除需要二次确认，并返回受影响引用数量。

### 7. 知识关系图

```text
GET /api/v1/courses/{course_id}/knowledge-graph?chapterId=&pointId=
```

响应：

```json
{
  "nodes": [
    {
      "id": "uuid",
      "type": "course|chapter|knowledge_point|resource",
      "label": "string",
      "parent_id": "uuid|null",
      "metadata": {}
    }
  ],
  "edges": [
    {
      "id": "uuid",
      "source": "uuid",
      "target": "uuid",
      "type": "contains|prerequisite|related|assessed_by|sourced_from",
      "weight": 1.0,
      "evidence_count": 3
    }
  ]
}
```

验收：图谱和紧凑预览使用真实关系；接口为空时展示章节树，不生成模拟边。

### 8. 资源元数据与索引状态

```text
GET /api/v1/courses/{course_id}/documents/{document_id}/index-status
GET /api/v1/courses/{course_id}/documents/{document_id}/citations?cursor=&limit=20
```

`index-status` 至少返回：`pages_total`、`pages_parsed`、`chunks_total`、`chunks_embedded`、`last_indexed_at`、`error`。

验收：资源详情 Index 和 Citations 页签显示真实状态；不显示“待接口”占位。

## P1：学生长期证据

```text
GET /api/v1/courses/{course_id}/students/{student_id}/mastery-trend?days=90
GET /api/v1/courses/{course_id}/students/{student_id}/error-patterns?days=90
```

用途：学生详情长期趋势与错误画像。响应字段与知识点趋势、错误聚类保持一致，并在每条数据中返回可回查的 event 或 snapshot ID。

## 前端接入顺序

1. PDF 文件流与页级定位。
2. 知识点掌握趋势和常见错误聚类。
3. 示例、习题、实验资源。
4. 外部资源、回收站、恢复。
5. 知识关系图。
6. 资源索引状态与学生长期证据。

## 非目标

- 前端不根据 LearningEvent 数量自行计算“置信度”或风险分数。
- 前端不猜测知识点关系、题型、难度或页码。
- 前端不把空数组解释成“没有错误”或“已经掌握”。
- 没有接口时保持明确的不可用状态，不增加 Mock 分支。
