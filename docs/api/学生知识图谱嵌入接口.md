# 学生知识图谱 WebView 嵌入接口

状态：后端已实现，版本 `v0.0.234`，API 版本 `0.0.233`，Alembic head `b1c2d3e4f5a6`。

## 创建一次性票据

```http
POST /api/v1/courses/{course_id}/knowledge-graph/embed-session
Authorization: Bearer <student_access_token>
```

仅当前课程中的有效 `student` 成员可调用。归档课程返回 `403`，未知课程返回 `404`。

```json
{
  "ticket": "opaque-random-ticket",
  "expires_in_seconds": 300
}
```

票据只返回一次，数据库只保存 SHA-256 哈希。

## 交换只读 token

```http
POST /api/v1/knowledge-graph/embed-sessions/exchange
Content-Type: application/json
```

```json
{
  "ticket": "opaque-random-ticket",
  "courseId": "course-uuid"
}
```

```json
{
  "access_token": "scoped-embed-access-token",
  "token_type": "Bearer",
  "expires_in_seconds": 300,
  "course_id": "course-uuid"
}
```

票据只能消费一次。已过期、已消费或课程不匹配统一返回 `410`，未知课程返回 `404`。

## 只读访问范围

嵌入 token 的 claims 包含：

```text
sub
course_id
scope=knowledge_graph:read
session_id
exp
```

允许读取：

```text
GET /api/v1/courses/{course_id}/knowledge-graph
GET /api/v1/courses/{course_id}/chapters
```

路径课程必须与 token 的 `course_id` 一致。嵌入 token 使用独立 `type`，不能通过通用 `CurrentUser`，因此不能调用知识点编辑、关系生成、资源管理或其他写接口。

## 安全约束

- 不把 ticket 或 access token 写入 URL、日志或 console。
- 每次读请求重新校验学生账号状态和课程成员关系。
- 教师权限保持原来的课程教师校验。
- 普通学生 Bearer token 仍不能直接访问教师图谱接口。
