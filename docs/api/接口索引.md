# API 接口索引

本文件记录 `@echo/api-client` 对外方法与后端接口的映射。教师端和学生端统一通过此客户端访问 API，不在页面组件中直接拼接请求。

待开发接口统一登记在 [`教师端缺失接口需求_v1.md`](./教师端缺失接口需求_v1.md)，教学策略与执行计划契约见 [`教学策略与执行计划接口需求_v1.md`](./教学策略与执行计划接口需求_v1.md)。前端不得为本文件未列出的接口增加 Mock 或本地推断数据。
AI 二次分析契约见 [`AI二次分析接口_v1.md`](./AI二次分析接口_v1.md)，该契约已由后端实现。

`createApiClient` 可通过 `getAccessToken` 注入当前 Access Token；存在时所有请求使用 `Authorization: Bearer`，否则保留开发环境 `X-User-Id` 回退。

> 当前索引版本：`v0.0.234`；教师端 AI 助手 v2 契约已新增 `capabilities`、非流式消息和 SSE 流式消息三条路径，OpenAPI 以运行时 `/api/v1/openapi.json` 为准。
