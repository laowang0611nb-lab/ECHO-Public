# API 接口索引

本文件记录 `@echo/api-client` 对外方法与后端接口的映射。教师端和学生端统一通过此客户端访问 API，不在页面组件中直接拼接请求。

待开发接口统一登记在 [`教师端缺失接口需求_v1.md`](./教师端缺失接口需求_v1.md)，教学策略与执行计划契约见 [`教学策略与执行计划接口需求_v1.md`](./教学策略与执行计划接口需求_v1.md)。前端不得为本文件未列出的接口增加 Mock 或本地推断数据。

## 系统与身份

| 客户端方法 | 后端接口 | 用途 |
|---|---|---|
| `health()` | `GET /api/v1/health` | 服务存活检查 |
| `getSystemStatus(userId)` | `GET /api/v1/system/status` | 本地部署只读状态、数据库目标、AI、文件和局域网检查 |
| `getDemoStatus(userId)` | `GET /api/v1/demo/status` | 隔离 Demo 数据集状态与固定上下文 ID |
| `resetDemoData(userId)` | `POST /api/v1/demo/reset` | 重建隔离 Demo 数据集，不触碰真实课程 |
| `login(payload)` | `POST /api/v1/auth/login` | 开发登录 |
| `me(userId)` | `GET /api/v1/auth/me` | 恢复当前用户 |
| `getTeacherProfile(userId)` | `GET /api/v1/auth/me/profile` | 读取当前教师完整资料 |
| `updateTeacherProfile(userId, payload)` | `PATCH /api/v1/auth/me/profile` | 更新当前教师资料，支持 `teacher_no` 作为 `employee_no` 别名 |
| `changePassword(userId, payload)` | `POST /api/v1/auth/change-password` | 验证当前密码、更新 Hash 并撤销旧 Session |

## 课程与成员

| 客户端方法 | 后端接口 | 用途 |

| `restoreCourse(userId, courseId)` | `POST /api/v1/courses/{course_id}/restore` | 将归档课程恢复为草稿 |
