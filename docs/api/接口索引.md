# API 接口索引

本文件记录 `@echo/api-client` 对外方法与后端接口的映射。教师端和学生端统一通过此客户端访问 API，不在页面组件中直接拼接请求。

## 系统与身份

| 客户端方法 | 后端接口 | 用途 |
|---|---|---|
| `health()` | `GET /api/v1/health` | 服务存活检查 |
| `login(payload)` | `POST /api/v1/auth/login` | 开发登录 |
| `me(userId)` | `GET /api/v1/auth/me` | 恢复当前用户 |

## 课程与成员

| 客户端方法 | 后端接口 | 用途 |
|---|---|---|
| `listCourses(userId)` | `GET /api/v1/courses` | 获取当前用户课程 |
| `createCourse(userId, payload)` | `POST /api/v1/courses` | 创建课程 |
| `joinCourse(userId, code)` | `POST /api/v1/courses/join` | 通过课程码加入 |
| `publishCourse(userId, courseId)` | `POST /api/v1/courses/{course_id}/publish` | 发布课程 |
| `listCourseMembers(userId, courseId)` | `GET /api/v1/courses/{course_id}/members` | 获取课程成员 |

## 教材与知识库

| 客户端方法 | 后端接口 | 用途 |
|---|---|---|
| `listCourseDocuments(userId, courseId)` | `GET /api/v1/courses/{course_id}/documents` | 教材列表与状态 |
| `uploadCourseDocument(userId, courseId, file, fileName?)` | `POST /api/v1/courses/{course_id}/documents` | 上传 PDF，multipart 字段为 `file` |
| `parseCourseDocument(userId, documentId)` | `POST /api/v1/documents/{document_id}/parse` | 页级文本解析 |
| `generateKnowledgeStructure(userId, documentId)` | `POST /api/v1/documents/{document_id}/generate-structure` | 生成章节与知识点 |
| `createDocumentChunks(userId, documentId)` | `POST /api/v1/documents/{document_id}/chunks` | 创建重叠知识块 |
| `createDocumentEmbeddings(userId, documentId)` | `POST /api/v1/documents/{document_id}/embeddings` | 批量生成向量 |
| `searchCourse(userId, courseId, payload)` | `POST /api/v1/courses/{course_id}/search` | 课程范围相似度检索 |

## 章节与知识点

| 客户端方法 | 后端接口 | 用途 |
|---|---|---|
| `listChapters(userId, courseId)` | `GET /api/v1/courses/{course_id}/chapters` | 获取课程结构 |
| `createChapter(userId, documentId, payload)` | `POST /api/v1/documents/{document_id}/chapters` | 新建章节 |

| `deleteChapter(userId, chapterId)` | `DELETE /api/v1/chapters/{chapter_id}` | 删除章节 |
| `createKnowledgePoint(userId, chapterId, payload)` | `POST /api/v1/chapters/{chapter_id}/knowledge-points` | 新建知识点 |
| `updateKnowledgePoint(userId, pointId, payload)` | `PATCH /api/v1/knowledge-points/{point_id}` | 修改或移动知识点 |
| `deleteKnowledgePoint(userId, pointId)` | `DELETE /api/v1/knowledge-points/{point_id}` | 删除知识点 |
| `mergeKnowledgePoints(userId, courseId, payload)` | `POST /api/v1/courses/{course_id}/knowledge-points/merge` | 合并知识点 |

## AI 回答审核

| 客户端方法 | 后端接口 | 用途 |
|---|---|---|
| `listReviewFlags(userId, courseId, options?)` | `GET /api/v1/courses/{course_id}/review-flags` | 获取审核队列 |
| `queryReviewFlags(userId, courseId, options?)` | `GET /api/v1/courses/{course_id}/review-flags/query` | 审核队列服务端筛选、排序与游标分页 |
| `getReviewSummary(userId, courseId)` | `GET /api/v1/courses/{course_id}/review-flags/summary` | 审核状态与风险汇总 |
| `getReviewFlag(userId, courseId, flagId)` | `GET /api/v1/courses/{course_id}/review-flags/{flag_id}` | 获取审核详情 |
| `getReviewContext(userId, courseId, flagId)` | `GET /api/v1/courses/{course_id}/review-flags/{flag_id}/context` | 获取审核问题、版本、历史、策略冲突和近期学习证据 |
| `regenerateReview(userId, courseId, flagId, payload)` | `POST /api/v1/courses/{course_id}/review-flags/{flag_id}/regenerate` | 按教师指令重生成回答并创建新版本 |
| `getReviewRegeneration(userId, courseId, flagId)` | `GET /api/v1/courses/{course_id}/review-flags/{flag_id}/regeneration` | 查询重生成状态和进度 |
| `listReviewVersions(userId, courseId, flagId)` | `GET /api/v1/courses/{course_id}/review-flags/{flag_id}/versions` | 获取回答版本列表 |
| `getReviewHistory(userId, courseId, flagId)` | `GET /api/v1/courses/{course_id}/review-flags/{flag_id}/history` | 获取教师决定和重生成审核历史 |
| `decideReviewFlag(userId, courseId, flagId, payload)` | `POST /api/v1/courses/{course_id}/review-flags/{flag_id}/review` | 确认、标记错误或忽略 |
| `reportMessageNotResolved(userId, courseId, messageId, payload)` | `POST /api/v1/courses/{course_id}/messages/{message_id}/not-resolved` | 学生标记未解决 |
