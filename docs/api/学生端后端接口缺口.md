# 学生端后端接口缺口

本文记录学生端确认缺失、不能在 Android 端伪造的后端能力。缺少这些接口的功能只保留路由、UI 骨架或明确占位，不自行发明请求路径。

> `v0.0.111` 已补齐学生课程进度、学习记录、错题、知识点巩固题、学生资源、教材来源、相关会话、教师信息、计划任务、错因证据、正式认证和课程公告。

> `v0.0.118` 修复 `GAP-AUTH-001`：`/auth/sms/verify` 的 `purpose` 必填；注册只接受 `register`，重置只接受 `password_reset`，验证票据不可跨用途复用。

## 当前状态

| 能力 | 当前状态 | Android 处理 |
|---|---|---|
| 正式账号密码登录 | `POST /auth/register/sms`、`POST /auth/login/password`、`POST /auth/password/reset`、Refresh/Logout 已实现 | 可接入正式手机号和密码会话 |
| Session 恢复 | Access JWT + Refresh Session 已实现，支持 `Authorization: Bearer` | 可通过 Refresh Token 恢复正式会话 |
| 学生 Profile / 学号 | 手机号和个人资料基础已具备，`student_no` 尚未单独暴露 | “我的”继续保留学号待同步 |
| 课程教师信息 | `GET /courses/{id}/teachers` 已实现 | 课程页面可展示真实教师 |
| 当前章节 / 学习进度 / 最近学习位置 | `GET /courses/{id}/students/{student_id}/progress` 已实现 | 使用服务端进度和完成规则 |
| 加入课程前预览 | 继续使用课程码加入确认流程 | 不伪装预览数据 |
| 学习记录 | `GET /courses/{id}/students/{student_id}/learning-events` 已实现 | 展示真实事件、掌握前后值和证据 |
| 错题整理与再次练习 | 错题列表/详情和按知识点巩固题已实现 | `/wrong-questions` 使用 QuickCheckAttempt 证据 |
| Hint / Quick Check / Mastery Update | 已实现结构化 block、Hint 请求、幂等提交和服务端掌握度更新 | 已接入 Android `/chat` |
| 学生版课程资料 | `GET /courses/{id}/student-resources` 已实现 | ResourceListSheet 可接入只读资源 |
| 知识点教材来源与页码 | `GET /courses/{id}/knowledge-points/{id}/sources` 已实现 | 展示文档、页码、Chunk 和原文 |
| 知识点相关对话 | 由 LearningEvent 的 `knowledge_point_id + conversation_id` 正式关联 | 不使用文本关键词猜测 |
| 学生本周任务 | `GET /courses/{id}/students/{student_id}/plan-tasks` 已实现 | 展示已发布计划和完成证据 |
| 学生错因 | `GET /courses/{id}/students/{student_id}/knowledge-points/{id}/misconceptions` 已实现 | 证据不足时明确标记 |
| 课程公告 | `POST/GET /courses/{id}/announcements` 和公告已读接口已实现 | 可展示已发布公告和已读状态 |

## USB ADB 开发约束

当前开发环境使用：

```powershell
adb reverse tcp:8000 tcp:8000
adb reverse tcp:8081 tcp:8081
```

Android 的 `EXPO_PUBLIC_API_BASE_URL` 使用：

```text
http://127.0.0.1:8000
```
