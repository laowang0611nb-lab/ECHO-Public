# 学生端后端接口缺口

本文记录第一阶段实现时确认缺失、不能在 Android 端伪造的后端能力。缺少这些接口的功能只保留路由、UI 骨架或明确占位，不自行发明请求路径。

> 第二阶段已解除 Hint / Quick Check / Mastery Update / 知识点上下文 / Citation Snapshot 缺口；下列其他能力仍按占位处理。

## 第一阶段阻塞

| 能力 | 当前状态 | Android 处理 |
|---|---|---|
| 正式账号密码登录 | 当前后端只有开发登录 `email + display_name + role`，没有学号/账号密码、Access/Refresh Token | 保留账号密码 UI 和 `StudentAuthService` 接口；仅开发模式可使用现有开发登录 |
| Session 恢复 | 没有正式登录 Session 和 Refresh API | 本地只保存当前开发用户；正式 Session 等后端认证完成 |
| 学生 Profile / 学号 | `User` 没有 `student_no`，数据库 V1 的 `student_profiles` 尚未接入 API | “我的”显示学号待同步 |
| 课程教师信息 | `Course` 没有教师姓名，学生不能读取教师的完整成员列表 | 课程页面显示授课教师待同步 |
| 当前章节 / 学习进度 / 最近学习位置 | 没有学生课程进度和最近学习位置接口 | 课程/AI 助学显示当前章节、学习进度待同步 |
| 加入课程前预览 | 只有 `POST /courses/join`，没有课程码预览接口 | 输入课程码后使用确认 Sheet，确认成功后再展示真实课程 |
| 最近课程动态 | 没有学生自己的 LearningEvent 列表接口 | 显示暂无学习动态 |
| 学习记录 | 没有学生自己的 LearningEvent 聚合/列表接口 | `/learning-records` 暂为占位页 |
| 错题整理与再次练习 | 没有 Question/Quiz 表和学生作答接口 | `/wrong-questions` 暂为占位页 |
| Hint / Quick Check / Mastery Update | 已实现结构化 `block`、Hint 请求、Quick Check 幂等提交、服务端掌握度更新和中断续写 | 已接入 Android `/chat` |
| 学生版课程资料 | `GET /courses/{id}/documents` 仅课程教师可访问 | 学生端不直接调用该接口 |
| 知识点教材来源与页码 | 没有学生可用的章节/知识点来源接口 | 知识点详情暂只保留占位 |
| Chat 上下文扩展 | 已支持 `clientRequestId` 和 `knowledgePointId`；Conversation 仍由 `courseId + userId` 隔离 | Android 使用真实课程和知识点上下文 |
| 换个角度 / 回答版本 | 生成接口属于教师审核工作流，没有学生端接口 | AI 对话下一阶段再接 |

## USB ADB 开发约束

当前开发环境使用：

```powershell
adb reverse tcp:8000 tcp:8000
adb reverse tcp:8081 tcp:8081
```

Android 的 `EXPO_PUBLIC_API_BASE_URL` 使用：

```text
http://127.0.0.1:8000
```

当前不实现 Local Server 设置、服务器发现、IP 输入或二维码服务器切换。比赛演示阶段由环境变量切换到教师电脑热点地址，不修改业务代码。

## 后端完成后

后端补齐接口后应优先解除：

1. 正式登录与 Session。
2. 学生课程进度与当前章节。
3. LearningEvent 学习记录。
4. Question/Quiz 与错题。
5. 学生个人 LearningEvent / 错题再次练习接口。

解除前不进入对应 Android 页面实现。
